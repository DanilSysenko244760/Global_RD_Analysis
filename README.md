# 🌍 Global R&D Analysis: Spending vs. Human Capital

## 📌 Project Overview
This project presents a comprehensive analysis of the relationship between **R&D (Research and Development) expenditure** and **researcher density** across varying economies from 2000 to 2021.

The primary objective is to evaluate how financial investment correlates with human capital development in the science and technology sectors, supporting the monitoring of **SDG 9 (Industry, Innovation, and Infrastructure)**.

👉 **[View Interactive Dashboard](https://www.novypro.com/project/global-rd-analysis)**

---

## 🔎 Key Insights

The data analysis reveals specific trends in global innovation strategies:

* **Correlation Analysis:** A Pearson correlation coefficient of **0.807** confirms a strong positive linear relationship between R&D spending (% of GDP) and the number of researchers per million inhabitants.
* **Leading Economies:** Countries such as **Israel, South Korea, and Sweden** demonstrate a high-efficiency model, maintaining R&D investments above 4% of GDP.
* **Regional Disparities:** The analysis highlights a significant gap between developed and developing nations. While OECD countries show steady growth, many nations in the Global South report stagnant investment levels (<0.5% GDP).

## 📊 Dashboard Architecture

The reporting tool is structured to guide the user from general overview to specific metrics:

1.  **Introduction & Scope:** Defines the problem statement and data limitations (2000-2021 timeframe).
2.  **Exploratory Data Analysis (EDA):** Geospatial visualization of researcher distribution.
3.  **Statistical Findings:** Detailed breakdown of central tendencies (Mean/Median) and correlation scatter plots.
4.  **Strategic Recommendations:** Data-driven suggestions for policy-making, including international resource sharing and benchmarking systems.

---

## ⚙️ Technical Implementation

* **Data Processing:** ETL procedures performed using Power Query for data cleaning and normalization.
* **Modeling:** Star schema data model optimized for time-series analysis.
* **Visualization:** Custom interactive navigation and dynamic filtering by region/year.
